## 毕业项目选题建议

每个选题都能用公开数据完成，难度从 ★ 到 ★★★。

| # | 选题 | 数据 | 难度 |
|---|---|---|---|
| 1 | 用 ESM 嵌入预测蛋白热稳定性或可溶性，并与传统特征对比 | ProteinGym、公开 DMS 数据 | ★ |
| 2 | 在严格的骨架划分下比较分子性质预测方法（指纹 / GNN / 预训练模型） | TDC、Polaris | ★ |
| 3 | 训练启动子 / 增强子活性预测模型，并用解释方法发现基序 | ENCODE、公开 MPRA 数据 | ★★ |
| 4 | 用 AlphaGenome API 或开源 DNA 模型为一组 GWAS 位点做变异效应注释 | GWAS Catalog、GTEx | ★★ |
| 5 | 系统比较单细胞基础模型嵌入与 PCA 基线在细胞注释上的表现 | CELLxGENE Census | ★★ |
| 6 | 复现一篇扰动预测论文的核心结果，并加入线性基线 | Perturb-seq 公开数据 | ★★ |
| 7 | 设计并计算评估某靶点的结合蛋白（生成 → 反向折叠 → 结构预测过滤） | PDB 中的靶点结构 | ★★★ |
| 8 | 搭建能检索文献、调用数据库并给出带引用回答的领域智能体 | PubMed、UniProt API | ★★ |
| 9 | 用 Cellpose 微调分割自己的显微图像，并提取形态特征做表型分析 | 自有数据或公开图像集 | ★★ |
| 10 | 结合你自己的研究课题：把实验室数据变成一个机器学习问题 | 自有数据 | ★–★★★ |

## 项目仓库模板

```
my-project/
├── README.md          # 问题、数据、方法、结果、如何复现
├── environment.yml    # 环境依赖
├── data/              # 只放下载脚本或小样例，不提交大文件
├── notebooks/         # 探索性分析
├── src/               # 可复用代码
├── results/           # 图表与指标
└── report.md          # 技术报告：背景 → 方法 → 结果 → 局限 → 下一步
```

README 必答五问：**解决什么问题？用了什么数据（怎么划分）？和什么基线比？结果如何（含误差 / 置信区间）？局限是什么？**
