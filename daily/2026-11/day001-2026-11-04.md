## 📖 核心概念

### 1. 为什么是现在

“AI × 生命科学”不是新话题，但最近十年发生了质变，主要来自三股力量的汇合：

- **数据爆炸**：测序成本持续下降，公共数据库飞速增长。PDB 收录的实验结构已超过 20 万个，AlphaFold DB 提供了 2 亿多条预测结构，CELLxGENE 汇集了数千万个单细胞。
- **算法突破**：卷积网络（CNN）、Transformer、图神经网络（GNN）、扩散模型（diffusion model）相继成熟，而且都能很自然地迁移到序列、结构、分子这类生物数据上。
- **标志性成功**：AlphaFold2 在 2020 年 CASP14 中把蛋白质结构预测精度推到接近实验水平。2024 年诺贝尔化学奖授予 David Baker（计算蛋白质设计）以及 Demis Hassabis 和 John Jumper（蛋白质结构预测），标志着 AI 方法被生命科学主流正式认可。

### 2. 一张地图：模态 × 任务

学这个领域，最好先把问题放进一张二维表里：**数据是什么形态**（模态），以及**要做什么**（任务）。

| 数据模态 | 常见表示 | 预测类任务 | 生成 / 设计类任务 | 代表模型与工具 |
|---|---|---|---|---|
| DNA / RNA 序列 | one-hot、k-mer、token | 调控活性、基因表达、剪接、变异效应 | 增强子 / 启动子设计、基因组设计 | DeepSEA、Enformer、Borzoi、AlphaGenome、Evo 2 |
| 蛋白质 | 序列、多序列比对（MSA）、3D 结构 | 结构、功能、突变效应 | 骨架生成、序列设计、结合蛋白设计 | AlphaFold2/3、ESM-2/ESM3、RFdiffusion、ProteinMPNN、BoltzGen |
| 小分子 | SMILES、分子图、3D 构象 | 性质、活性、ADMET、结合亲和力 | 分子生成、逆合成 | Chemprop、DiffDock、Boltz-2、REINVENT |
| 细胞（单细胞组学） | 基因 × 细胞表达矩阵 | 细胞类型、细胞状态、扰动响应 | “虚拟细胞”模拟 | scVI、Geneformer、scGPT、State |
| 图像 | 像素 / 体素 | 分割、分类、表型识别 | 去噪、图像恢复 | U-Net、Cellpose、StarDist、病理基础模型 |
| 文本与知识 | token、知识图谱 | 信息抽取、问答 | 假设生成、实验规划 | PubMedBERT、PaperQA、Biomni |

把这张表记在脑子里，以后读到任何一篇新论文，都先问两个问题：**它处理哪种模态？做的是预测还是设计？** 大部分论文都能很快归位。

### 3. 三类核心问题

1. **预测（prediction）**：给定输入，输出性质。例如从序列预测结构、从分子预测毒性。这是目前最成熟的一类。
2. **理解（interpretation）**：模型为什么这样预测？例如从训练好的 DNA 模型里“读出”转录因子基序，从而发现新的调控规律。对生物学研究来说，这一步往往比预测精度本身更有价值。
3. **设计（design）**：反过来，给定想要的性质，生成新的序列、蛋白或分子。生成模型（扩散、流匹配、语言模型）让这一类问题在 2022 年后进展飞快。

最近又多了第四类：**自动化（automation）**。大语言模型智能体（agent）开始帮助检索文献、写分析代码、规划实验，形成“AI 提出假设 → 实验验证 → 数据反馈给 AI”的闭环。

### 4. 里程碑时间线

| 年份 | 里程碑 |
|---|---|
| 2012 | AlexNet 赢得 ImageNet 竞赛，深度学习时代开始 |
| 2015 | DeepBind、DeepSEA：用 CNN 从 DNA 序列预测蛋白结合和染色质特征 |
| 2017 | Transformer（“Attention Is All You Need”）提出 |
| 2018 | 第一代 AlphaFold 在 CASP13 夺冠；scVI 把深度生成模型用于单细胞数据 |
| 2020 | AlphaFold2 在 CASP14 达到接近实验的精度 |
| 2021 | AlphaFold2 论文发表并开源，AlphaFold DB 上线；RoseTTAFold、Enformer 发表 |
| 2022 | ESM-2 / ESMFold；ProteinMPNN；AlphaFold DB 扩展到 2 亿多条结构 |
| 2023 | RFdiffusion 发表于 Nature；单细胞基础模型 Geneformer、scGPT 出现 |
| 2024 | AlphaFold3 与 ESM3 发布；诺贝尔化学奖授予蛋白质设计与结构预测；开源的 Boltz-1 发布 |
| 2025 | Evo 2 预印本；Boltz-2 联合预测结构与结合亲和力；AlphaGenome 预览；Biomni 智能体；Arc Institute 首届 Virtual Cell Challenge；RFdiffusion3 开源 |
| 2026 | AlphaGenome（1 月）与 Evo 2（3 月）正式发表于 Nature；OpenFold3 重大更新；CASP17 结果将在 11 月底至 12 月的 CASP17 会议前公布 |

一个明显的趋势是：**从“一个任务一个模型”走向“基础模型（foundation model）+ 下游任务”**，从“只做预测”走向“预测 + 设计 + 自动化”。但也要保持清醒：在单细胞扰动预测等任务上，已有研究发现大模型还比不过简单的线性基线（第 22 周会专门讨论）。

## 🛠️ 动手练习

打开 [Google Colab](https://colab.research.google.com/)，新建一个 Notebook，先运行 `!pip install biopython`，再运行下面的代码。它把一段 DNA 翻译成蛋白质，然后从 AlphaFold DB 下载这个蛋白的预测结构，画出每个残基的置信度。

```python
import requests
import matplotlib.pyplot as plt
from io import StringIO
from Bio.Seq import Seq
from Bio.SeqUtils import gc_fraction
from Bio.PDB import PDBParser

# 1) 从 DNA 到蛋白：人 HBB 基因编码区的前 30 个碱基
dna = Seq("ATGGTGCATCTGACTCCTGAGGAGAAGTCT")
print("GC 含量:", round(gc_fraction(dna), 3))
print("翻译结果:", dna.translate())          # 期望输出 MVHLTPEEKS

# 2) 从 AlphaFold DB 获取人血红蛋白 β 链（UniProt P68871）的预测结构
uid = "P68871"
entry = requests.get(f"https://alphafold.ebi.ac.uk/api/prediction/{uid}", timeout=30).json()[0]
pdb_text = requests.get(entry["pdbUrl"], timeout=60).text

# 3) AlphaFold 把每个残基的 pLDDT 存在 PDB 文件的 B-factor 列
structure = PDBParser(QUIET=True).get_structure(uid, StringIO(pdb_text))
plddt = [res["CA"].get_bfactor() for res in structure.get_residues() if "CA" in res]
print("残基数:", len(plddt), "  平均 pLDDT:", round(sum(plddt) / len(plddt), 1))

# 4) 画出每个残基的置信度（图中标签用英文，避免 Colab 缺中文字体）
plt.figure(figsize=(8, 3))
plt.plot(range(1, len(plddt) + 1), plddt)
plt.axhline(70, ls="--", c="gray")
plt.xlabel("Residue index")
plt.ylabel("pLDDT")
plt.title(f"AlphaFold confidence: {uid}")
plt.tight_layout()
plt.show()
```

**进阶**：把 `uid` 换成一个含有无序区的蛋白，例如人 p53（UniProt：P04637），比较两条 pLDDT 曲线有什么不同。

> 如果 AlphaFold DB 的接口格式有变动，可以在网页上直接下载 PDB 文件，再用 `PDBParser` 读取本地文件。
