## 📖 核心概念

### 1. 为什么是 Python

生物 AI 的主要工具几乎都是 Python：PyTorch、scikit-learn、Biopython、RDKit、scanpy、Hugging Face。Python 本身运行不快，但计算密集的部分都由底层的 C/C++/CUDA 代码完成。我们写 Python，主要是把这些高效的“积木”组织起来。

### 2. 心智模型：名字指向对象

`a = [1, 2, 3]` 的意思不是“把列表装进盒子 a”，而是“创建一个列表对象，再贴上名字 a”。`b = a` 只是给同一个对象多贴了一个名字，所以通过 `b` 修改，`a` 也会变（这叫别名）。

- **不可变对象**：数字、字符串、元组。“修改”时其实是创建了新对象。DNA 序列用字符串表示，所有“修改”都会返回新字符串。
- **可变对象**：列表、字典、集合。可以原地修改，所以要小心别名。

### 3. 选对数据结构

| 结构 | 特点 | 生信例子 | 判断“是否包含” |
|---|---|---|---|
| 列表 `list` | 有序、可变、可重复 | 一组 reads、按顺序的表达量 | 逐个比较，数据越多越慢 |
| 元组 `tuple` | 有序、不可变 | 一个坐标 `("chr1", 1000, 1200)`；可以当字典的键 | 逐个比较 |
| 字典 `dict` | 键 → 值的映射 | 密码子表、基因 ID → 注释 | 哈希查找，几乎不随数据量变慢 |
| 集合 `set` | 无序、元素唯一 | 差异表达基因列表的交集、并集 | 哈希查找，几乎不随数据量变慢 |

要在 2 万个基因 ID 里反复查找，就用集合或字典，不要用列表。练习前的测试里，在 10 万个 ID 中查找，集合比列表快上万倍。`collections.Counter` 是专门用来计数的字典，统计 k-mer、细胞类型非常方便。

### 4. 写出清楚的代码

- **推导式**：`[s for s in seqs if len(s) > 100]`、`{codon: aa for codon, aa in pairs}`，比手写循环更短也更清楚。
- **函数**：一个函数只做一件事；写文档字符串（docstring）说明输入和输出；加类型提示（`def gc_content(seq: str) -> float`），编辑器能帮你发现错误。
- **`@dataclass`**：定义“记录型”的类（一个基因、一个变异），自动生成 `__init__`、`__repr__` 和 `__eq__`；还可以在 `__post_init__` 里检查数据是否合法，比如起点不能大于终点。
- **模块**：把函数放进 `.py` 文件，别的脚本或 Notebook 用 `import seqtools` 就能复用。`if __name__ == "__main__":` 下面的代码只在直接运行这个文件时执行，被导入时不执行。
- **异常与 `with`**：数据不合法时主动 `raise ValueError(...)`，不要让错误数据悄悄流到后面的步骤；打开文件用 `with open(...) as f:`，出错时文件也会被正确关闭。
- **生成器**：函数里用 `yield` 逐条产出结果，而不是一次性返回整个列表。读几 GB 的 FASTA 或 FASTQ 时，内存里永远只有一条记录。

### 5. 常见陷阱

| 陷阱 | 例子 | 正确做法 |
|---|---|---|
| 可变默认参数 | `def f(x, items=[])`：这个列表只在定义函数时创建一次，多次调用会共用 | 用 `items=None`，在函数里新建列表 |
| 别名 | `[[0] * 3] * 2` 的两行其实是同一个列表 | `[[0] * 3 for _ in range(2)]`；需要副本时用 `.copy()` |
| 浮点数比较 | `0.1 + 0.2 == 0.3` 结果是 `False` | `math.isclose(0.1 + 0.2, 0.3)` |
| 切片约定 | `seq[2:5]` 取的是第 3–5 个碱基，长度为 3 | 记住“从 0 开始、终点不包含”，和 BED 格式（Day 005）一致 |
| `is` 与 `==` | `is` 判断是不是同一个对象，`==` 判断值是否相等 | 比较值用 `==`；只有和 `None` 比较时用 `is` |

**第 1 步：写一个序列工具模块。** 把下面的代码存为 `seqtools.py`（Colab 里可以在单元格第一行写 `%%writefile seqtools.py`，运行后就会存成文件）：

```python
"""seqtools.py：几个常用的序列小工具，用来练习 Python 核心语法。"""
from collections import Counter
from dataclasses import dataclass
from itertools import product

COMPLEMENT = str.maketrans("ACGTNacgtn", "TGCANtgcan")

# 标准遗传密码（NCBI 第 1 号表）：按 T、C、A、G 顺序排列的 64 个密码子
BASES = "TCAG"
AMINO = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
CODON_TABLE = {"".join(codon): aa for codon, aa in zip(product(BASES, repeat=3), AMINO)}


def reverse_complement(seq: str) -> str:
    """返回反向互补序列。"""
    return seq.translate(COMPLEMENT)[::-1]


def gc_content(seq: str) -> float:
    """GC 含量（忽略大小写）。"""
    seq = seq.upper()
    return (seq.count("G") + seq.count("C")) / len(seq) if seq else 0.0


def translate(seq: str, to_stop: bool = False) -> str:
    """按标准遗传密码把 DNA 翻译成蛋白；末尾不足 3 个碱基的部分直接丢弃。"""
    protein = []
    for i in range(0, len(seq) - 2, 3):
        aa = CODON_TABLE.get(seq[i:i + 3].upper(), "X")   # 含 N 等字符的密码子记为 X
        if aa == "*" and to_stop:
            break
        protein.append(aa)
    return "".join(protein)


def kmer_counts(seq: str, k: int) -> Counter:
    """统计所有长度为 k 的子串出现的次数。"""
    return Counter(seq[i:i + k] for i in range(len(seq) - k + 1))


def read_fasta(path):
    """逐条读取 FASTA，产出 (标题, 序列)。这是生成器：再大的文件也不会一次读进内存。"""
    header, chunks = None, []
    with open(path) as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            if line.startswith(">"):
                if header is not None:
                    yield header, "".join(chunks)
                header, chunks = line[1:], []
            else:
                chunks.append(line)
    if header is not None:
        yield header, "".join(chunks)


@dataclass
class Gene:
    name: str
    chrom: str
    start: int          # 从 1 开始、包含两端（与 GTF 一致）
    end: int
    strand: str = "+"

    def __post_init__(self):
        if self.start > self.end:
            raise ValueError(f"{self.name}: start ({self.start}) 不能大于 end ({self.end})")
        if self.strand not in ("+", "-"):
            raise ValueError(f"{self.name}: strand 只能是 '+' 或 '-'")

    @property
    def length(self) -> int:
        return self.end - self.start + 1

    def to_bed(self) -> str:
        """转成 BED 行：起点减 1（BED 从 0 开始、终点不包含）。"""
        return f"{self.chrom}\t{self.start - 1}\t{self.end}\t{self.name}\t0\t{self.strand}"


if __name__ == "__main__":
    dna = "ATGGTGCATCTGACTCCTGAGGAGAAGTCT"      # 人 HBB 编码区的前 30 个碱基
    print("反向互补:", reverse_complement(dna))
    print("GC 含量:", round(gc_content(dna), 3))
    print("翻译:", translate(dna))
    print("最常见的 3-mer:", kmer_counts(dna, 3).most_common(3))
    gene = Gene("geneA", "chr1", 1000, 5000)
    print(gene, "长度:", gene.length)
    print("BED:", gene.to_bed())
```

```python
import math

def add_sample(name, samples=[]):        # ❌ 默认的列表只在定义函数时创建一次
    samples.append(name)
    return samples
print(add_sample("A"), add_sample("B"))  # 输出 ['A', 'B'] ['A', 'B']：两次调用共用同一个列表

def add_sample_ok(name, samples=None):   # ✅ 用 None 占位，每次调用新建列表
    samples = [] if samples is None else samples
    samples.append(name)
    return samples
print(add_sample_ok("A"), add_sample_ok("B"))    # 输出 ['A'] ['B']

grid = [[0] * 3] * 2                     # ❌ 两行其实是同一个列表
grid[0][0] = 1
print(grid)                              # 输出 [[1, 0, 0], [1, 0, 0]]

print(0.1 + 0.2 == 0.3, math.isclose(0.1 + 0.2, 0.3))   # 输出 False True

seq = "ATGGTGCAT"
print(seq[0:3], seq[3:6], len(seq[2:5]))  # 输出 ATG GTG 3
```

**进阶：用 Biopython 交叉验证。** 自己写的函数要和成熟的工具对一对。安装 Biopython（`pip install biopython`）后运行：

```python
import random
from Bio.Seq import Seq
from seqtools import translate

random.seed(0)
for _ in range(1000):
    s = "".join(random.choice("ACGT") for _ in range(random.randrange(3, 300)))
    s = s[: len(s) - len(s) % 3]          # 只取 3 的整数倍长度

print("1000 条随机序列与 Biopython 的翻译结果一致")
```

## ✅ 自测题

1. 要在 2 万个基因 ID 里反复判断“某个 ID 在不在其中”，用列表还是集合？为什么？
2. `def add_sample(name, samples=[])` 有什么问题？怎么改？
3. 对字符串 `seq` 来说，`seq[2:5]` 取的是第几到第几个碱基（从 1 开始数）？这种约定和哪种文件格式一致？
4. 什么时候应该用生成器而不是返回一个列表？举一个生信的例子。
5. `@dataclass` 自动生成了哪些方法？`__post_init__` 适合用来做什么？

<details>
<summary>参考答案</summary>

1. 用集合（或字典）。集合用哈希表存储，判断成员几乎不随数据量变慢；列表要从头到尾逐个比较，数据越多越慢。练习前的测试里，在 10 万个元素中查找，集合比列表快上万倍。
2. 默认值在定义函数时只计算一次，所以所有不传 `samples` 的调用共用同一个列表，数据会越积越多。改成 `samples=None`，在函数里写 `samples = [] if samples is None else samples`。
3. 取的是第 3、4、5 个碱基（索引 2、3、4），长度为 3。Python 切片从 0 开始、终点不包含，与 BED 格式的坐标约定一致。
4. 数据量大、只需要逐条处理时。例如逐条读取几 GB 的 FASTQ 文件做质控：生成器每次只把一条 read 放进内存；如果一次性读成列表，可能直接耗尽内存。
5. 自动生成 `__init__`、`__repr__`、`__eq__`（还可以按参数生成排序方法等）。`__post_init__` 在 `__init__` 之后运行，适合检查数据是否合法（如起点不大于终点、链方向只能是 `+` 或 `-`），或者计算派生字段。
