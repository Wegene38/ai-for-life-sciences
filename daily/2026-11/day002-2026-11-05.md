## 📖 核心概念

### 1. 为什么先自评

26 周要覆盖编程、数学、机器学习、深度学习和六个生物方向，任何人都不可能每一天都从零学起。自评的目的是**把时间花在边际收益最大的地方**：已经掌握的快速通过，真正的短板放慢脚步、多做练习。

自评最大的陷阱是“熟悉感错觉”：看过、听过，就以为会了。重读笔记会让内容显得很眼熟，但眼熟不等于能用。所以下面的打分标准一律问“**能不能做到**”，而不是“有没有学过”。

### 2. 用“能做到”来打分

0 分 = 看资料也很吃力；1 分 = 看资料能做到；2 分 = 不查资料能独立做到。

| 维度 | 2 分的标准（不查资料） |
|---|---|
| Python | 写一个函数读取 FASTA 文件，返回每条序列的 GC 含量 |
| 工程习惯 | 新建 conda 环境，用 Git 提交改动并推送到 GitHub |
| 线性代数 | 解释为什么 PCA 的主成分是协方差矩阵的特征向量 |
| 概率统计 | 解释为什么对 2 万个基因做差异表达检验必须做 FDR 校正 |
| 分子与细胞生物学 | 讲清启动子、增强子、转录因子与基因表达之间的关系 |
| 生物信息学 | 说出 FASTQ、BAM、VCF 各存什么，以及 RNA-seq 分析的主要步骤 |
| 机器学习 | 解释为什么蛋白数据要按序列相似度划分训练集和测试集 |
| 深度学习 | 写出 PyTorch 训练循环：前向传播、计算损失、反向传播、参数更新 |

拿不准时就当场试一下。比如“深度学习”这一项，打开一个空白 Notebook，五分钟内写不出训练循环，就不是 2 分。打分结果对照 [ROADMAP.md 第 1 节](../../ROADMAP.md#1-先做自评) 的表格，就能知道哪些天可以快速浏览。

### 3. 选路线

- **路线 A（生物 / 医学 / 计算生物学背景）**：生物学和数据分析是你的优势，主要补数学推导与深度学习工程。计算生物学背景的学习者通常擅长统计和生信流程，短板多在第 3–4 周的矩阵与概率推导，以及第 8–11 周用 PyTorch 从零写模型。建议这两段放慢，周复盘项目一个都不要跳过。
- **路线 B（计算机 / 数学背景）**：机器学习有基础，主要补生物学。第 2–4 周可以快速浏览，把时间留给第 5 周，并在每个专题开始前先补该方向的生物背景。

无论哪条路线，第 6–13 周的核心内容（数据划分、Transformer、GNN、生成模型）都建议认真学，后面的专题都建立在这些内容之上。

### 4. 有证据的学习方法

Dunlosky et al. 2013 系统评估了 10 种常见学习方法，评价最高（“高效用”）的两种是：

- **主动回忆 / 自测（retrieval practice）**：合上书，凭记忆回答问题。提取记忆这个动作本身就能加固记忆，效果明显好于重读。所以每篇笔记的自测题一定要**先自己作答，再展开答案**。
- **间隔重复 / 分散练习（spaced repetition / distributed practice）**：同样的总时长，分散到多天、间隔越来越长地复习，比集中突击记得更久。常用的复习间隔是 1 天、3 天、1 周、2 周、1 个月。[Anki](https://apps.ankiweb.net/)（电脑版和安卓版免费）会自动帮你排复习时间。

被评为“低效用”的恰恰是最常见的做法：反复重读、划重点、做摘要。它们让人感觉很努力，但对长期记忆帮助有限。

另外两种在本课程里也会用到：

- **费曼学习法（Feynman technique）**：试着用简单的话把一个概念讲给外行听，卡住的地方就是没真正懂的地方，回头重学，再讲一遍。每天写 3–5 句“今天学到了什么”就是一个简化版本。
- **交错练习（interleaving）**：把不同类型的问题混在一起练（Dunlosky 等评为“中等效用”）。每周复盘日混合练习一周的内容，就是在做交错练习。

### 5. 制定能坚持的计划

- **固定时间块**：比如每天早上 7:30–9:00。笔记每天早上 7 点前更新，正好接上。
- **最低节奏**：特别忙的日子只做两件事：今天的自测题 + 一个核心资源。保持不断档，比偶尔学满三小时更重要。
- **记录进度**：fork 本仓库，在自己的副本里勾选打卡框；第 13 周和第 26 周各重新自评一次，对比雷达图的变化。
- **落后了不要补课式追赶**：按自己的节奏往下走，笔记会一直留在仓库里。

**进阶：用代码理解间隔重复。** 下面是最简单的间隔重复算法“莱特纳盒子”（Leitner system）：答对就升一级、下次间隔变长；答错就回到第 1 级。

```python
import datetime as dt

# 莱特纳盒子（Leitner system）：答对升一级、间隔变长；答错回到第 1 级
INTERVALS = [1, 3, 7, 14, 30]   # 第 1–5 级的复习间隔（天）

def review(level, correct, today):
    """复习一张卡片，返回新的级别和下次复习日期。"""
    level = min(level + 1, len(INTERVALS) - 1) if correct else 0
    return level, today + dt.timedelta(days=INTERVALS[level])

# 模拟一张卡片：前两次答对，第 3 次答错，之后一直答对
level, day = 0, dt.date(2026, 11, 5)
for correct in [True, True, False, True, True, True]:
    level, day = review(level, correct, day)
    print(f"{'答对' if correct else '答错'} → 第 {level + 1} 级，下次复习 {day}")
```

期望输出的最后一行是 `答对 → 第 4 级，下次复习 2026-12-10`。然后把今天的 5 道自测题写成 Anki 卡片（每张卡只问一件事），明天开始复习。
