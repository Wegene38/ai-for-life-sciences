## 📖 核心概念

### 1. 为什么要专门学“读论文”

AI × 生物的论文增长很快：bioRxiv、arXiv 每天都有新预印本，还有顶刊和机器学习会议。不可能每篇都精读，所以第一项本事是**筛选**。第二个难点是这类论文横跨两个领域：机器学习读者容易忽略生物学上的合理性，生物学读者容易被漂亮的指标打动。关键细节（数据划分、超参数、基线设置）还常常藏在补充材料和代码里。

### 2. 三遍阅读法（Keshav）

| 遍数 | 时间 | 做什么 | 结束时应该能 |
|---|---|---|---|
| 第一遍 | 5–10 分钟 | 读标题、摘要、引言、各级小标题和结论，扫一眼图和参考文献 | 回答“五个 C”，决定要不要继续读 |
| 第二遍 | 约 1 小时 | 仔细读正文，跳过证明和过细的推导；重点看图表，记下没读过的重要参考文献 | 向别人讲清这篇论文的主要内容和证据 |
| 第三遍 | 数小时 | 在脑子里（或用代码）“重新实现”这篇论文，逐条质疑它的假设 | 说出它的创新点、隐藏的假设和不足 |

第一遍的“五个 C”是：**类别**（Category：方法、资源、应用还是综述？）、**背景**（Context：和哪些已有工作相关？）、**正确性**（Correctness：基本假设看起来成立吗？）、**贡献**（Contributions：主要贡献是什么？）、**清晰度**（Clarity：写得清楚吗？）。

大多数论文读完第一遍就够了。只有你要在其基础上做研究、或要复现的论文，才值得读第三遍。

### 3. 拆解 AI × 生物论文的 8 个问题

1. **生物学问题**：要解决什么问题？为什么重要？
2. **输入与输出**：属于 Day 001 地图里的哪种“模态 × 任务”？
3. **数据与划分**：数据从哪来、有多大？训练集和测试集按什么划分（序列同源性、分子骨架、时间、患者）？有没有泄漏的可能？
4. **模型与训练目标**：用了什么架构？损失函数是什么？是预训练加微调，还是从头训练？
5. **基线**：和哪些方法比较？**有没有包括简单基线**？
6. **评估**：用了哪些指标？有没有误差线或多次重复？有没有独立测试集或前瞻性验证？
7. **生物学验证**：有湿实验或新的生物学发现，还是只有计算指标？
8. **可复现性与局限**：代码、数据、模型权重是否公开？作者承认了哪些局限？

这 8 个问题就是练习里“论文卡片”的骨架。读多了你会发现，AI × 生物论文最常见的问题集中在第 3、5、6 条。

### 4. 读图表的技巧

- 图 1 通常是方法总览示意图，先看懂它，正文会好读很多。
- 看基准表时，先找三样东西：**测试集是怎么划分的、基线有哪些、结果是几次运行的平均**。
- **消融实验**（ablation）告诉你模型里哪些部分真正有用。
- 补充材料里常有超参数、数据处理细节和失败案例，第二遍要翻一翻。

### 5. 常见“红旗”

- 测试集和训练集高度相似（同源蛋白、近似分子），却声称“泛化能力强”。
- 只和过时或很弱的基线比较。
- 只报告最好的一次运行，没有方差。
- 类别不平衡的数据只报准确率（accuracy）。
- 只在单个基准上领先，就宣称达到最好水平（state of the art）。
- 不公开代码和数据。

还要记住：预印本没有经过同行评审，读的时候要更谨慎；但同行评审也不等于结论一定正确。本课程第 22 周会讲到两个例子：单细胞基础模型在零样本任务上不如高变基因基线，扰动预测模型不如线性基线。这正是“先问有没有简单基线”的意义。

### 6. 搭建文献追踪系统

- **管理**：[Zotero](https://www.zotero.org/) 免费开源，装好浏览器插件后，在论文页面点一下就能保存条目和 PDF。免费云存储 300 MB，只有 PDF 等附件占空间。按课程模块建文件夹，再建一个“待读”文件夹。
- **信息源**：bioRxiv 的分类邮件提醒和 RSS（[Alerts/RSS 页面](https://www.biorxiv.org/alertsrss)）；arXiv 的 q-bio 新论文列表；Google Scholar 的关键词或作者提醒；关注期刊的目录推送；本仓库的 [前沿速递](../../frontier/README.md)。
- **节奏**：每周固定一段时间处理“待读”：所有论文读第一遍，挑 2–3 篇读第二遍，每月精读一篇。每读一篇，在 Day 004 建的学习仓库里留一张论文卡片。
- **AI 辅助**：可以用大语言模型帮你快速了解一篇论文，但它可能编造细节，结论一定要回到原文核对（第 13、24 周会学检索增强和文献智能体）。

**第 2 步：自动生成待读清单。** 在 Colab 里运行下面的代码。它通过 arXiv 官方 API 检索两个主题的最新论文，生成一个带复选框的 Markdown 清单（只用 Python 标准库，不用装任何包）：

```python
import time
import urllib.parse
import urllib.request
import xml.etree.ElementTree as ET

ATOM = {"a": "http://www.w3.org/2005/Atom"}

def search_arxiv(query, max_results=5):
    """用 arXiv 官方 API 检索最新论文，返回 (日期, 标题, 链接) 列表。"""
    params = urllib.parse.urlencode({
        "search_query": query,
        "sortBy": "submittedDate",
        "sortOrder": "descending",
        "max_results": max_results,
    })
    with urllib.request.urlopen(f"https://export.arxiv.org/api/query?{params}", timeout=30) as resp:
        root = ET.fromstring(resp.read())
    papers = []
    for entry in root.findall("a:entry", ATOM):
        title = " ".join(entry.find("a:title", ATOM).text.split())   # 去掉标题里的换行
        link = entry.find("a:id", ATOM).text
        date = entry.find("a:published", ATOM).text[:10]
        papers.append((date, title, link))
    return papers

queries = {
    "蛋白质语言模型": 'cat:q-bio.BM AND abs:"language model"',
    "单细胞基础模型": 'abs:"single-cell" AND abs:"foundation model"',
}
lines = ["# 待读清单"]
for topic, query in queries.items():
    lines.append(f"\n## {topic}\n")
    for date, title, link in search_arxiv(query):
        lines.append(f"- [ ] {date} [{title}]({link})")
    time.sleep(3)          # arXiv 要求连续请求之间至少间隔 3 秒
with open("reading_queue.md", "w", encoding="utf-8") as f:
    f.write("\n".join(lines) + "\n")
print("\n".join(lines))
```

期望输出：每个主题下列出 5 篇最新论文，格式如 `- [ ] 2026-11-06 [论文标题](http://arxiv.org/abs/…)`。具体论文取决于运行当天。把 `queries` 改成你自己关心的方向，比如 `abs:"protein design"` 或 `cat:q-bio.GN`。

**第 3 步：搭好 Zotero。** 按今日资源 4 安装 Zotero 和浏览器插件，建立“01 基础”“02 ML/DL”“03 基因组”“04 蛋白质”“05 药物”“06 单细胞”“07 影像”“08 智能体”“待读”这些文件夹，把 AlphaFold2 论文存进去。

1. 第一遍 5–10 分钟，了解全貌并决定是否继续；第二遍约 1 小时，掌握主要内容和证据，但不深究细节；第三遍数小时，通过“重新实现”理解全部细节，找出隐藏的假设和不足。五个 C：类别（Category）、背景（Context）、正确性（Correctness）、贡献（Contributions）、清晰度（Clarity）。
2. 例如：（1）测试集怎么划分：是否按序列相似度划分，测试蛋白和训练蛋白是否高度同源；（2）和哪些方法比较：有没有简单基线（如 BLAST 同源注释），基线是否过时；（3）指标是否合适、是否稳健：类别不平衡时只看准确率会误导，应看 PR-AUC、F1 等，还要看是否有多次重复和误差范围。
3. 预印本没有经过同行评审，可能有错误，结论也可能在正式发表前改变；好处是能最早看到新进展。读预印本时要特别检查方法和数据是否交代清楚、代码是否公开、结论是否超出证据，并留意后续版本的修改。同行评审能过滤一部分问题，但不能保证结论正确，读正式论文也要保持批判。
4. 复杂模型的优势必须相对于合理的简单方法才有意义；如果连简单基线都没比，就无法判断复杂模型是否真的有用。例子：Ahlmann-Eltze et al. 2025 发现，基因扰动预测的深度学习模型并不比简单的线性基线好；Kedzierska et al. 2025 发现，在零样本设置下，scGPT、Geneformer 常常不如直接使用高变基因。
5. 开放题。示例：信息源是 bioRxiv 的 bioinformatics 分类 RSS、arXiv q-bio.BM 和 q-bio.GN、两个作者的 Google Scholar 提醒、本仓库的前沿速递；每周一早上处理一次待读文件夹，全部读第一遍，挑 2 篇读第二遍；每篇在学习仓库里留一张论文卡片，每月精读并尝试复现一篇。
