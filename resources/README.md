# 📚 资源库

这里收录**免费**、**高质量**、适合系统学习的资源，按方向分类。课程表里每天引用的资源都能在这里找到。

## 收录标准

1. **免费**：可以免费阅读或观看。需要注册、可免费旁听或部分免费的会注明。
2. **高质量**：顶尖机构或领域权威作者出品，或者是社区公认的经典。
3. **能动手**：优先收录带代码、Notebook 或练习的资源。
4. **仍然可用**：2026 年 11 月建库时核实过：GitHub 仓库逐个确认存在，其他链接以官方页面为准并经网络搜索核实。之后每周复盘日会检查并补充新资源。
