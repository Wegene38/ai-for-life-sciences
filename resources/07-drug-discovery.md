## 核心工具

| 工具 | 用途 |
|---|---|
| ⭐ [RDKit](https://github.com/rdkit/rdkit) | 化学信息学基础库：分子读写、描述符、指纹、子结构 |
| ⭐ [Chemprop](https://github.com/chemprop/chemprop) | 消息传递网络做分子性质预测 |
| [DeepChem](https://github.com/deepchem/deepchem) | 分子机器学习工具集 |
| 🇨🇳 [Uni-Mol（深势科技）](https://github.com/deepmodeling/Uni-Mol) | 3D 分子表示学习框架 |
| 🇨🇳 [OpenBioMed](https://github.com/PharMolix/OpenBioMed) | 面向生物医药的多模态 AI 工具包 |
| [ADMET-AI](https://github.com/swansonk14/admet_ai) | 快速 ADMET 性质预测 |
| [AutoDock Vina](https://autodock-vina.readthedocs.io/) | 经典分子对接 |
| [DiffDock](https://github.com/gcorso/DiffDock) | 扩散模型做分子对接 |
| [Boltz-2](https://github.com/jwohlwend/boltz) | 结构 + 亲和力联合预测（MIT 许可） |
| [REINVENT4](https://github.com/MolecularAI/REINVENT4) | 分子生成与优化 |
| [AiZynthFinder](https://github.com/MolecularAI/aizynthfinder) | 逆合成规划 |
| [TorchDrug](https://github.com/DeepGraphLearning/torchdrug) | 药物发现机器学习平台（近年更新较少） |

## 数据与基准

| 资源 | 说明 |
|---|---|
| [ChEMBL](https://www.ebi.ac.uk/chembl/) · [PubChem](https://pubchem.ncbi.nlm.nih.gov/) · [ZINC](https://zinc.docking.org/) | 生物活性数据与可购买化合物库 |

| [MoleculeNet](https://moleculenet.org/) | 经典分子性质基准 |
