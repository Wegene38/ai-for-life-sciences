## 核心数据库

| 数据库 | 内容 |
|---|---|
| [NCBI](https://www.ncbi.nlm.nih.gov/) | 序列、文献（PubMed）、基因、GEO 等的总入口 |
| [Ensembl](https://www.ensembl.org/) · [UCSC Genome Browser](https://genome.ucsc.edu/) | 基因组注释与浏览器 |
| [UniProt](https://www.uniprot.org/) | 蛋白质序列与功能注释 |
| [RCSB PDB](https://www.rcsb.org/) | 实验测定的生物大分子结构 |
| [AlphaFold DB](https://alphafold.ebi.ac.uk/) | 2 亿+ 条 AlphaFold 预测结构 |
| [ChEMBL](https://www.ebi.ac.uk/chembl/) · [PubChem](https://pubchem.ncbi.nlm.nih.gov/) | 生物活性小分子与化合物 |
| [GEO](https://www.ncbi.nlm.nih.gov/geo/) | 基因表达数据 |
| [ENCODE](https://www.encodeproject.org/) · [GTEx](https://gtexportal.org/) | 调控元件、组织表达与 eQTL |
| [GDC](https://portal.gdc.cancer.gov/) | 癌症基因组（TCGA 等） |
| [CZ CELLxGENE](https://cellxgene.cziscience.com/) | 单细胞数据集合 |
| 🇨🇳 [国家基因组科学数据中心（NGDC）](https://ngdc.cncb.ac.cn/) | 国内组学数据汇交与共享平台 |

更多数据集与基准见 [11 数据、基准与竞赛](11-data-benchmarks-competitions.md)。
