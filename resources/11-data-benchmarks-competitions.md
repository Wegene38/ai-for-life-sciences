## 数据库速查

| 方向 | 数据库 |
|---|---|
| 序列与基因组 | [NCBI](https://www.ncbi.nlm.nih.gov/) · [Ensembl](https://www.ensembl.org/) · [UCSC](https://genome.ucsc.edu/) · 🇨🇳 [NGDC](https://ngdc.cncb.ac.cn/) |
| 调控与表达 | [ENCODE](https://www.encodeproject.org/) · [GTEx](https://gtexportal.org/) · [GEO](https://www.ncbi.nlm.nih.gov/geo/) |
| 蛋白质 | [UniProt](https://www.uniprot.org/) · [RCSB PDB](https://www.rcsb.org/) · [AlphaFold DB](https://alphafold.ebi.ac.uk/) |
| 小分子 | [ChEMBL](https://www.ebi.ac.uk/chembl/) · [PubChem](https://pubchem.ncbi.nlm.nih.gov/) · [ZINC](https://zinc.docking.org/) |
| 单细胞 | [CZ CELLxGENE](https://cellxgene.cziscience.com/) · [Human Cell Atlas](https://data.humancellatlas.org/) |
| 癌症 | [GDC（TCGA 等）](https://portal.gdc.cancer.gov/) |
| 知识图谱 | [PrimeKG](https://github.com/mims-harvard/PrimeKG) |
| 影像 | [JUMP Cell Painting](https://github.com/jump-cellpainting/datasets) · [BioImage Model Zoo](https://bioimage.io/) |

## 基准

| 基准 | 任务 |
|---|---|
| ⭐ [ProteinGym](https://proteingym.org/) | 蛋白突变效应预测 |
| ⭐ [TDC](https://tdcommons.ai/) | 药物研发全流程任务 |
| ⭐ [Polaris](https://polarishub.io/) | 药物发现，强调规范评估 |

| [BEND](https://github.com/frederikkemarin/BEND) | DNA 语言模型 |
| [Open Problems](https://openproblems.bio/) | 单细胞分析任务 |
| [CAMEO](https://www.cameo3d.org/) | 每周持续进行的结构预测盲测 |
| [LAB-Bench](https://github.com/Future-House/LAB-Bench) | AI 完成生物研究任务 |

> Papers with Code 已于 2025 年 7 月关闭，原网址跳转到 [Hugging Face Trending Papers](https://huggingface.co/papers/trending)，原有排行榜未完整继承。看排行榜时优先以各基准的官方页面为准。

## 竞赛与社区挑战

| 竞赛 | 状态（截至 2026-11） |
|---|---|
| ⭐ [CASP17](https://predictioncenter.org/casp17/) | 2026 年预测季已于 9 月结束，评估结果在 CASP17 会议（11 月底至 12 月）前公布；新增抗体-抗原、TCR 等免疫复合物类别 |
| ⭐ [Virtual Cell Challenge](https://virtualcellchallenge.org/) | 2026 年第二届进行中：跨细胞环境泛化与零样本扰动预测 |
| [Stanford RNA 3D Folding（Kaggle）](https://www.kaggle.com/competitions/stanford-rna-3d-folding) | 2025 年第一轮；2026 年 1–3 月第二轮（已结束），赛后方案是很好的学习材料 |
| [CAFA 5 蛋白功能预测（Kaggle）](https://www.kaggle.com/competitions/cafa-5-protein-function-prediction) | 已结束，可练手；CAFA 6 于 2025–2026 年在 Kaggle 举办 |
| [Open Problems – Single-Cell Perturbations（Kaggle）](https://www.kaggle.com/competitions/open-problems-single-cell-perturbations) | 2023 年，已结束，可练手 |
| 🆕 [BioReasoning Challenge 2026](https://genentech.github.io/BioReasoningChallenge/) | ICLR 2026 MLGenX 研讨会挑战赛 |
| [DREAM Challenges](https://dreamchallenges.org/) | 长期举办的生物医学众包挑战 |

> 已结束的 Kaggle 比赛通常仍可“迟交”（Late Submission）评分，讨论区和获奖方案是宝贵的学习材料。
